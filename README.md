# СтеныПро — Лендинг покраски и поклейки обоев

Одностраничный лендинг (SPA) для бизнеса по профессиональной покраске и поклейке обоев в Москве и Московской области. Построен на **Vue 3** + **Vite**, развёрнут на **Firebase Hosting** с предварительным рендерингом (SSG) для улучшения SEO.

## Возможности

**Квиз-форма** — 7 шагов для уточнения деталей заказа: тип работы, площадь, материалы, сроки и контакты клиента. По завершении пользователь попадает на страницу `/thank-you.html`.

**Быстрая заявка** — модальное окно «Узнать стоимость» доступно без прохождения полного квиза из шапки и нескольких CTA-блоков.

**Переключаемые вкладки** — динамический контент для двух услуг: «Покраска обоев» и «Поклейка обоев».

**Валидация форм** — проверка российского номера телефона и email на стороне клиента, автоматическое форматирование телефона при вводе.

**Отправка данных через EmailJS** — результаты квиза и быстрой формы уходят на почту владельца без серверной части.

**Адаптивный дизайн** — поддержка мобильных устройств (360px+), планшетов и десктопов. Бургер-меню с анимацией для мобильных.

**Анимации при скролле** — Intersection Observer плавно проявляет секции при появлении в области видимости. Поддержка `prefers-reduced-motion`.

**Статический пререндеринг (SSG)** — Puppeteer обходит готовый Vite Preview сервер и сохраняет отрендеренный HTML в `dist/index.html`, улучшая SEO и скорость первой загрузки.

**Яндекс.Метрика** — счётчик с вебвизором, кликмапом и электронной коммерцией; цель `form_submit` фиксируется при переходе на страницу благодарности.

## Быстрый старт

### Требования

- Node.js 18+
- npm 9+
- Firebase CLI (для деплоя): `npm install -g firebase-tools`

### Установка

```bash
git clone <repository-url>
cd stenepro-oboi-vue
npm install
```

### Локальная разработка

```bash
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173).

## Переменные окружения

Создайте файл `.env` в корне проекта на основе `.env.example`:

```env
VITE_EMAILJS_PUBLIC_KEY=your_public_key
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_YANDEX_METRIKA_ID=your_metrika_id
```

Все переменные начинаются с `VITE_` — Vite автоматически подставляет их в клиентский код. Файл `.env` добавлен в `.gitignore` и **не должен попадать в репозиторий**.

Чтобы получить значения EmailJS: зарегистрируйтесь на [emailjs.com](https://www.emailjs.com/), создайте сервис, шаблон и скопируйте ключи из раздела «Account → API Keys».

## Сборка и деплой

### Только сборка (Vite + пререндеринг)

```bash
npm run build
```

Команда выполняет два шага:

1. `vite build` — собирает SPA в папку `dist/`
2. `node prerender.mjs` — запускает Vite Preview на порту 3033, открывает страницу через Puppeteer и перезаписывает `dist/index.html` отрендеренным HTML

> **Замечание по платформам:** `prerender.mjs` содержит вызов `taskkill` для завершения процесса на Windows. На Linux/macOS используется `SIGTERM` — он срабатывает первым, поэтому скрипт работает на всех платформах.

### Предпросмотр сборки

```bash
npm run preview
```

### Деплой на Firebase

```bash
npm run deploy
# или вручную:
firebase login
firebase deploy
```

Firebase Hosting отдаёт содержимое папки `dist/`. Конфигурация в `firebase.json` исключает из деплоя `firebase.json`, скрытые файлы и `node_modules`.

## SEO и аналитика

**Мета-теги** — заполнены title, description, keywords, canonical, geo-теги, Open Graph и Twitter Card.

**JSON-LD разметка** — два блока:

- `LocalBusiness` — название, адрес, телефон, email, координаты, рейтинг, часы работы, зоны обслуживания
- `FAQPage` — 3 вопроса с ответами

**itemprop-атрибуты** — дополнительная разметка Schema.org прямо в HTML-шаблоне `App.vue`.

**Яндекс.Метрика** — инициализируется в `index.html` и `thank-you.html`. Цель `form_submit` отправляется при загрузке страницы благодарности.

**Sitemap** — `public/sitemap.xml`, путь прописан в `robots.txt`.

**Пререндеринг** — поисковые роботы получают полностью отрендеренный HTML вместо пустого `<div id="app">`.
